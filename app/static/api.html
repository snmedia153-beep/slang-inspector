API 문서

로컬 분석 API입니다. POST 요청의 Content-Type은 application/json입니다.

전체 OpenAPI 스키마 JSON 보기 →

POST /api/analyze
{"text":"ㄱㄷ ㄷㄸ","threshold":0.82,"discover":true}

GET /api/ocr/info      한국어 OCR 준비 상태
POST /api/ocr/analyze   PNG/JPEG/WebP 바이너리 본문, 10MB 이하
POST /api/ocr/reanalyze OCR 단어 수정 JSON {image_width,image_height,words}
GET /api/health       준비 상태
GET /api/context/info    로컬 문맥 모델 연결 및 참고 자료
POST /api/context/interpret    문맥 원형 비교 (text 최대 6,000자)
GET /api/dataset      수집 데이터 출처·라이선스·개수
GET /api/watchlist    문맥 검토 목록·풀이 근거·출처 조회
GET /api/lexicon      사전 조회
POST /api/lexicon     사전 등록
DELETE /api/lexicon/{id}    항목 삭제
POST /api/discover    문서 묶음 분석
GET /api/candidates   검토 대기 후보
DELETE /api/candidates/{id}    후보 제외

사전 등록 JSON
{"alias":"입력표현","expansion":"추정원형","canonical":"의미 또는 설명",
 "category":"사용자 사전","note":"출처·검토 메모","needs_context":true}

문서 묶음 JSON
{"texts":["첫 문서","다른 두 번째 문서"],"min_count":2}

원문은 저장하지 않으며, 사전과 후보 정보는 로컬 DB에 보관합니다. 점수는 확률이나 불법성 판정이 아닙니다.
